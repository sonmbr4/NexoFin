# NexoFin - Gestor de Finanzas

Aplicacion de gestiones financieras Aplicación de gestión financiera personal desarrollada con React. Permite llevar un control de ingresos y gastos de forma simple e intuitiva.

## Caracteristicas

- Balance total
- Registro de ingrsos y gastos
- Historial de movimientos
- Diseo MobileFirst

## Tecnologías

- React 19
- React Router

## Instalacion

1. Clonar Repositorio:

git clone https://github.com/sonmbr4/NexoFin.git

2. Instalar dependendias

cd nexofin
npm install

3. Inicia la aplicación

npm run dev

4. Abrir el LocalHost indicado (si no colocaste nada seguro se iniciare en el http://localhost:5173/)

## Uso

1. **Inicio**: Visualiza tu balance total y últimas transacciones
2. **Movimientos**: Agrega ingresos o registra gastos
3. **Actividad**: Consulta estadísticas e historial completo

Hecho con ❤️ para aprender React
